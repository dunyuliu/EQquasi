# evals

No agent evals exist for EQquasi yet.

This folder is for fixtures that score an agent's work on this repo: a task,
the repo state it starts from, and what a correct result looks like (for
example, "add a `bp == N` block without touching the existing ones" graded
against rules 6 and 13). Solver correctness does not go here; that is
`tests/` and the gold under `data/`.
