# Citing

EQquasi is released under the MIT License. If you use it in published work,
please cite:

1. [Liu, Duan and Luo (2020)](https://doi.org/10.1093/gji/ggz475),
   Geophys. J. Int., 220, 598-609. This paper presents the fully dynamic
   earthquake cycle simulator EQsimu, of which EQquasi is the quasi-dynamic
   part.
2. [Jiang et al. (2022)](https://doi.org/10.1029/2021JB023519), J. Geophys.
   Res. This is where EQquasi's SEAS BP5 results (v1.2.1) are published.

EQquasi solves its linear systems with MUMPS (http://mumps-solver.org),
which is distributed under the CeCILL-C license; please acknowledge MUMPS
as its license asks.

EQquasi does not yet have an archived, DOI-citable software release and the
repository has no `CITATION` file. Until one exists, cite the paper(s)
above and the GitHub repository, https://github.com/dunyuliu/EQquasi.
